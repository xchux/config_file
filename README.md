# config_file

Simple personal configuration files.

This repository stores my common tool settings in one place.
It helps me set up a new machine quickly and keep the same workflow.

Included config examples:
- git
- ruff
- tmux
- vim
- shell setup scripts
- AI agents (Claude Code / Codex / Gemini CLI / VS Code / Cursor / Antigravity) — see [ai-center](ai-center/README.md)
